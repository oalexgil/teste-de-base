# AdSignal Intelligence Demo

Open `adsignal/index.html` through a local HTTP server or GitHub Pages. The dashboard uses the shared domain engine under `src/` and the realistic demo dataset under `src/sample-data/`.

## What the demo proves

The same workspace produces, in one analysis:

- a media efficiency score;
- a lead quality score;
- a creative health score;
- one composite AdSignal score;
- CPL versus CPQL versus CAC;
- lead funnel quality;
- creative concept performance;
- prioritized evidence-based recommendations.

This is intentionally not three separate apps. The commercial proposition is a single decision layer over the acquisition funnel.
