# Campaign Economics

AdSignal compares campaigns using downstream acquisition economics, not lead volume alone.

For each campaign the domain layer can calculate:
- reported leads;
- CRM leads;
- qualified leads;
- meetings;
- sales;
- CPL;
- CPQL;
- cost per meeting;
- CAC;
- qualification rate;
- close rate;
- tracked ROAS.

This allows a campaign with a higher CPL to outrank a cheaper campaign when it produces substantially better qualified and won outcomes.
